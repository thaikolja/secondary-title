## Prerequisites

- WordPress **6.5 or newer**
- PHP **8.1 or newer**

## How to install

### From the WordPress admin

1. Go to **Plugins → Add New**.
2. Search for **"Secondary Title"**.
3. Click **Install Now**, then **Activate**.

### Manual upload

1. Download the plugin from [wordpress.org/plugins/secondary-title](https://wordpress.org/plugins/secondary-title/).
2. Upload the ZIP via **Plugins → Add New → Upload Plugin**.
3. Activate the plugin.

## How to verify installation

1. Open any post or page in the editor — the **Secondary Title** panel appears in the sidebar (block editor) or as a meta box (Classic Editor).
2. Go to **Settings → Secondary Title** to configure display options.
3. Enter a secondary title, save, and view the post on the front end.

::note
Upgrading from v2.x? Your post meta (`_secondary_title`) and settings are migrated automatically. All v2.x API functions continue to work as deprecated stubs.
::
