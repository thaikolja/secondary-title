Secondary Title adds a second title field to your WordPress posts, pages, and custom post types — next to the primary title, without touching its markup.

## What is Secondary Title?

The plugin stores a secondary title per post and gives you three ways to display it: merged into the post title automatically, rendered via a `[secondary_title]` shortcode, or placed anywhere with a native Gutenberg block. A classic editor meta box and a block-editor sidebar panel make editing quick in either editor.

The plugin is built around a small, typed PHP 8.1 core, uses the WordPress Settings API for storage, and renders its admin UI with Twig.

## What you can do

- **Auto-merge the secondary title** — combine it with the primary title using a configurable format like `%secondary_title%: %title%`.
- **Render it with a shortcode** — place `[secondary_title]` anywhere in your content, optionally with `post_id` and `allow_html`.
- **Place it with a Gutenberg block** — a native `/secondary-title` block, server-side rendered with no front-end JavaScript.
- **Call it from your theme** — use `the_secondary_title()` or the `Thaikolja\SecondaryTitle\Api` facade.
- **Restrict where it shows** — enable it per post type, category, or explicit post IDs.

## When to use Secondary Title

Use it when you need to:

- Add a subtitle, tagline, or kicker to posts without hacking your theme's title template.
- Keep the secondary title editable from both the Classic Editor and the block editor.
- Show a secondary title in feeds, columns, or archives with automatic formatting.
