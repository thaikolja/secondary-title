The `[secondary_title]` shortcode renders the secondary title wherever you place it in your content.

## Add the shortcode

Place it in any post, page, or reusable block:

```text
[secondary_title]
```

## Configure the attributes

| Attribute | Default | Description |
|---|---|---|
| `post_id` | `0` (current post) | Read the secondary title from another post. |
| `allow_html` | `false` | Render the stored value as HTML (`true`) or plain text (`false`). |

```text
[secondary_title post_id="42"]
[secondary_title post_id="42" allow_html="true"]
```

::note
With `allow_html="true"` the stored value is emitted as-is — it is sanitized via `wp_kses_post()` at save time. With the default `false`, tags are stripped and the output is escaped.
::

## Filter the output

Addons can rewrite the rendered shortcode output:

```php
add_filter(
    'secondary_title_shortcode',
    function ( string $output ): string {
        return '<span class="my-badge">' . $output . '</span>';
    }
);
```
