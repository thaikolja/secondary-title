Use the secondary title directly in theme templates, custom loops, or your own plugins.

## Use the template tags

The v2.x procedural API is preserved as deprecated stubs — they keep working and emit a deprecation notice:

```php
// Echo the secondary title (auto-merge aware).
the_secondary_title();

// Get it as a string.
$title = get_secondary_title();

// Check whether a post has one.
if ( has_secondary_title() ) {
    // ...
}
```

## Use the Api facade

New code should use the static facade:

```php
use Thaikolja\SecondaryTitle\Api;

$title = Api::get( get_the_ID() );

// Render the full formatted title for a post.
echo Api::render_title( get_the_ID() );

// Settings access.
$enabled = Api::is_auto_show();
$format  = Api::get_title_format();
```

## Hook the final output

```php
add_filter(
    'secondary_title_display',
    function ( string $rendered, string $template, string $title, string $secondary, int $post_id ): string {
        return '<p class="secondary-title">' . $rendered . '</p>';
    },
    10,
    5
);
```
