Auto-merge combines the secondary title with the post title on the front end, using a format you define.

## Enable auto-merge

1. Go to **Settings → Secondary Title → General**.
2. Turn on the **Auto-merge** toggle.
3. Choose the post types, categories, or post IDs where it should apply (**Display rules** tab).
4. Save.

## Use placeholders in the format

The format string supports two placeholders:

| Placeholder | Replaced with |
|---|---|
| `%title%` | The post's primary title |
| `%secondary_title%` | The post's secondary title (wrapped in `<span class="st-title">`) |

The default format is `%secondary_title%: %title%`.

## Customize the wrapper

Two filters control the wrapper element:

```php
add_filter( 'secondary_title_wrapper_tag', fn() => 'h3' );
add_filter( 'secondary_title_wrapper_class', fn() => 'subtitle' );
```

## Limit the length

```php
// Cut the secondary title to 40 characters.
add_filter( 'secondary_title_max_length', fn() => 40 );

// Change the truncation suffix (default '…', '' disables).
add_filter( 'secondary_title_trim_excess', fn() => ' [...]' );
```

## Run the output through wpautop

```php
add_filter( 'secondary_title_autop', '__return_true' );
```

## Handle the escaping

Stored values are sanitized on save via `wp_kses_post()` (limited HTML allowed). The exact allow-list is filterable:

```php
add_filter(
    'secondary_title_allowed_tags',
    function ( array $tags ): array {
        // Tighten or loosen the allow-list here.
        return $tags;
    }
);
```
