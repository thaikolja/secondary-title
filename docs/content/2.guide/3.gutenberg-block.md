A native `/secondary-title` block renders the secondary title on the canvas. It is server-side rendered, so no JavaScript loads on the front end.

## Insert the block

1. In the block editor, search for **"Secondary Title"** in the inserter.
2. Add the block anywhere in your content.
3. The secondary title renders using the configured format.

## Configure the block

The block has two attributes:

| Setting | Default | Description |
|---|---|---|
| **Post ID** | `0` (current post) | Render the secondary title of a different post. |
| **Wrapper tag** | `span` | The HTML element used as wrapper (`span`, `em`, `strong`, `small`). |

If the post has no secondary title, the block shows an empty-state placeholder that is invisible on the front end.

## Filter the source value

The raw value is filterable before it is substituted into the format:

```php
add_filter(
    'secondary_title_source',
    function ( string $secondary, int $post_id ): string {
        return strtoupper( $secondary );
    },
    10,
    2
);
```
