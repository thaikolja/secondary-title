The settings page (**Settings → Secondary Title**) is organized into three tabs.

## General

- **Auto-merge** — merge the secondary title into the post title on the front end.
- **Title format** — the placeholder template (`%secondary_title%: %title%` by default), with live preview.
- **Admin column position** — where the "Secondary title" column appears on the posts list screen (`After title` or `Before title`).

## Display rules

Control where the secondary title is shown:

- **Post types** — enable auto-merge for posts, pages, and custom post types (searchable multi-select).
- **Categories** — restrict auto-merge to specific categories (empty = all).
- **Specific post IDs** — only show on the listed post IDs (empty = all).

## Tools & Help

- **Quick Start** — copy-paste examples for the shortcode and PHP API.
- **Shortcode** — reference for `[secondary_title]`.
- **PHP API** — reference for the `Thaikolja\SecondaryTitle\Api` facade.
- **Changelog** — what changed in each release.

::note
The plugin uses the WordPress Settings API for storage. Options are kept 1:1 with v2 keys where they exist, so downgrading or cross-version tooling keeps working.
::
